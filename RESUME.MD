

# 🛒 Olist E-commerce SQL Analytics
## Project Overview

This project demonstrates the complete lifecycle of an analytical database using the Brazilian Olist E-commerce Dataset.

The objective is not only to write SQL queries, but to design and implement an end-to-end data pipeline, from raw CSV files to business insights.

**The project covers:**

>Database modeling (ERD / MLD) 
>PostgreSQL database design         
>Automated CSV import with Python         
>Data quality assessment         
>SQL business analysis         
>Query optimization         
>Documentation and reproducibility
